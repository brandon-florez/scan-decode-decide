# NutriScan Insight

# Diseño e Interfaz de Usuario — NutriLex

## 1. Concepto general

NutriLex tendrá una interfaz móvil **simple, limpia y fácil de entender**, diseñada para que cualquier persona pueda analizar un producto alimenticio en pocos segundos sin necesidad de conocer términos nutricionales o químicos.

El diseño utilizará principalmente **verde menta, blanco y tonos verdes suaves**, transmitiendo una sensación de salud, tranquilidad, limpieza y confianza.

La aplicación tendrá como principio:

**“Escanea, entiende y decide.”**

El usuario no deberá navegar por muchas opciones. La función principal siempre estará visible: **analizar una etiqueta nutrimental**.

---

### Color principal — Verde menta

* Fondos suaves.

* Tarjetas.

* Elementos destacados.

* Botones secundarios.

Representa salud, frescura y bienestar.

### Verde principal

Se utilizará para:

* Botones principales.

* Iconos importantes.

* Barra de navegación.

* Botón “Escanear etiqueta”.

### Blanco

**#FFFFFF**

Será el color predominante de la interfaz.

Se utilizará para:

* Fondo principal.

* Tarjetas.

* Espacios de contenido.

Esto permitirá que la aplicación se vea limpia y profesional.

### Verde oscuro

**#174A35**

Se utilizará para:

* Títulos.

* Texto importante.

* Nombre de NutriLex.

### Colores de advertencia

**Verde:** Bajo

**Rojo:** Alto

Estos colores funcionarán como un **semáforo nutricional**, haciendo que el usuario pueda entender el resultado rápidamente sin leer demasiada información.

---

# 3. Pantalla principal

La pantalla de inicio será la más sencilla.

En la parte superior aparecerá:

**🍃 NutriLex**

Debajo:

**“Entiende lo que comes.”**

Después habrá una tarjeta grande de color verde menta con el mensaje:

**¿Qué quieres analizar?**

Y solamente dos opciones:

### 📷 Escanear etiqueta

Botón grande de color verde.

El usuario podrá tomar una fotografía de la tabla nutrimental y los ingredientes.

### ✏️ Ingresar datos

Botón blanco con borde verde.

Permitirá escribir los datos manualmente cuando no sea posible utilizar la cámara.

La función de escaneo es especialmente importante porque el proyecto busca automatizar la decodificación de las etiquetas.

---

# 4. Pantalla de análisis

Después de escanear la etiqueta aparecerá una pantalla sencilla:

**Analizando producto...**

Se mostrará un indicador de carga durante el procesamiento.

Después:

**✓ Análisis terminado**

Y un botón:

**Ver resultado**

No se mostrará información técnica innecesaria durante esta etapa.

---

# 5. Pantalla de resultados

Esta será la pantalla más importante de NutriLex.

En la parte superior:

### Resultado del análisis

Después aparecerá el nombre del producto:

**Cereal de chocolate**

Y debajo una tarjeta grande:

## 🔴 NIVEL ALTO

**“Este producto contiene niveles elevados de algunos nutrientes. Se recomienda moderar su consumo.”**

Debajo aparecerán cuatro tarjetas sencillas:

| Nutriente   | Resultado   |

| ----------- | ----------- |

| 🍬 Azúcares | 🔴 Alto     |

| 🧂 Sodio    | 🟡 Moderado |

| 🥑 Grasas   | 🟢 Bajo     |

| ⚡ Calorías  | 🟢 Bajo     |

El usuario podrá entender el resultado **de un solo vistazo**.

---

# 6. Equivalencias fáciles

Una característica importante será convertir los números difíciles de interpretar en ejemplos cotidianos.

Por ejemplo:

**Azúcares**

12 g

≈ **3 cucharaditas**

**Sodio**

180 mg

≈ **⅓ cucharadita de sal**

Esto sigue directamente la idea del proyecto de presentar equivalencias claras para que el usuario no tenga que realizar cálculos manualmente.

---

# 7. Ingredientes y aditivos

Habrá un botón grande:

### 🧪 Ver ingredientes

Al presionarlo, aparecerá una lista sencilla.

Por ejemplo:

**Jarabe de maíz de alta fructosa**

¿Qué significa?

“Endulzante utilizado en algunos alimentos procesados.”

**Nivel:** 🔴 Alto

---

**Glutamato monosódico (E621)**

¿Qué significa?

“Potenciador de sabor utilizado en alimentos procesados.”

**Nivel:** 🟡 Moderado

---

El objetivo será **traducir los términos técnicos a palabras que una persona común pueda comprender**, que es uno de los objetivos centrales de NutriLex.

---

# 8. Recomendaciones

Al final del análisis aparecerá una tarjeta verde menta:

## 💡 Recomendación

**“Consume este producto con moderación.”**

Y debajo recomendaciones cortas:

✓ Busca alternativas con menos azúcar.

✓ Revisa el tamaño de la porción.

✓ Compara productos similares.

✓ Si tiene mucho sodio, considera otra opción.

No se deben mostrar párrafos largos. La aplicación debe dar **recomendaciones rápidas y fáciles de recordar**.

---

# 9. Barra de navegación

En la parte inferior del celular habrá solamente cuatro opciones:

**⌂ Inicio**

**📷 Escanear**

**🕘 Historial**

**💡 Consejos**

El botón **Escanear** será el más destacado porque representa la función principal de la aplicación.

---

# 10. Historial

El usuario podrá consultar productos analizados anteriormente.

Ejemplo:

**Cereal de chocolate**

🔴 Alto

Analizado hoy

**Galletas integrales**

🟡 Moderado

Analizado ayer

**Yogurt**

🟢 Bajo

Analizado hace 2 días

Esto permitirá comparar rápidamente los productos que consume normalmente.

---

# 11. Estilo visual

La aplicación tendrá:

* Bordes redondeados.

* Botones grandes.

* Iconos sencillos.

* Letras grandes y fáciles de leer.

* Mucho espacio en blanco.

* Tarjetas de información.

* Sombras muy suaves.

* Pocos elementos por pantalla.

* Verde menta como color característico.

* Blanco como fondo principal.

No se utilizarán demasiados colores ni gráficos complicados.

La prioridad será:

### **Simple → Claro → Rápido → Comprensible**

# 13. Diseño final

NutriLex debe sentirse más como una aplicación cotidiana de apoyo para hacer compras que como una herramienta académica complicada.

Al abrirla, el usuario debe saber inmediatamente qué hacer:

**“Escanear etiqueta”**

Después de escanear, debe poder responder rápidamente:

**¿Es bueno, moderado o alto?**

Y finalmente:

**¿Qué significa y qué debería considerar?**

De esta manera, la interfaz refleja directamente el propósito del proyecto: transformar tablas nutrimentales y nombres químicos difíciles de comprender en información clara, visual y útil para tomar decisiones alimentarias.
